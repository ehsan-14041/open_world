# Session observation sheet

One copy per session. Keep completed copies **outside the repository** (see
`FACILITATOR_PACK.md`, section 8). Refer to the participant by code only.

Three kinds of note are kept apart throughout:

- **Quote** — the owner's exact words, in quotation marks.
- **Observed** — what they did, which you saw.
- **Interpretation** — what you think it means. Always marked as yours.
