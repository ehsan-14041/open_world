# Customer validation pilot — start here

OWE's next milestone is **evidence that its workflow helps a small-business owner make or test a
meaningful decision**. More features, trades, tests or polished reports are not substitutes for
that evidence.

The workflow being tested:

> a real decision → a comparison under transparent assumptions → a practical experiment →
> observation → cautious revision of assumptions.

The primary pilot is the **café pricing** workflow. The shop and salon workflows stay
available, but they are not part of this pilot.

| Document | What it is for |
|---|---|
| [`EVIDENCE_AUDIT.md`](EVIDENCE_AUDIT.md) | What is verified, what is not, and the assumptions behind a café recommendation |
| [`FACILITATOR_PACK.md`](FACILITATOR_PACK.md) | Recruitment, the session script, the paid-follow-up test, follow-up contacts, data handling |
| [`OBSERVATION_TEMPLATE.md`](OBSERVATION_TEMPLATE.md) | One sheet per session |
| [`PILOT_SCORECARD.md`](PILOT_SCORECARD.md) | Scoring and continue / simplify / change / pause rules, fixed before session 1 |

These replace `docs/commercial/THREE_WEDGE_PROTOCOL.md` and `docs/commercial/SALES_SCRIPT.md`
for this phase.

## Running the first session — the short version

1. **Set the four owner decisions** in `FACILITATOR_PACK.md` §0 — above all the follow-up
   price — and freeze `PILOT_SCORECARD.md`.
2. **Upload the pilot build** and write its version (the zip name, or the site's `?version`
   output) at the top of the pack. Leave the question router off.
3. **Recruit** with the screening script (§1). Invite only owners who meet all five criteria.
4. **Print or open** one observation sheet per session.
5. **Run the session** in a fresh private browser window (§2–§3), 25–35 minutes, following the
   script and the neutrality rules (§4). Make the paid offer exactly as written (§5).
6. **Write it up the same day** (§7). Keep notes outside the repository.
7. **Follow up** at about two and six weeks (§6).
8. **After each batch of three**, apply the early-stop rule in the scorecard. After nine, read the
   scorecard and decide.

## Where session notes go

Not in git. Use a private folder outside this repository. If you need them beside the code, the
folder `pilot_sessions/` at the repository root is ignored by git.
