# Forecast tests on resolved Polymarket questions (November 2026)

Results: [`reports/forecast_test/RESULTS.md`](../../reports/forecast_test/RESULTS.md).
Protocols, written before the forecasts: `PROTOCOL.md` (engine arm) and `PROTOCOL_DOSSIER.md` (dossier arm).

> **Notice:** the files `batches/D1_*.json` hold dossiers a language model wrote from memory, including a
> "private" field per actor. Those fields are the model's guesses about real people and institutions, made
> for the test. They are not facts or reports. The paths in `batches/D_*.json` are likewise model output.

`data/questions.json` is public market data collected from the Polymarket API.
